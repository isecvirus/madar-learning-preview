# مَدار

منصة عربية للدورات القصيرة في المهارات العملية. تضم 3 دورات في Excel وكتابة السيرة الذاتية وتنظيم المهام، مع دروس مكتوبة وأمثلة وتدريبات واختبار في نهاية كل دورة.

![مدار](screenshots/00-preview.png)

## تجربة التعلّم

- تصفّح الدورات والبحث فيها والتصفية حسب المجال.
- 12 درسًا، لكل منها مثال عملي وسؤال للتطبيق.
- ملاحظات خاصة بكل درس، تُحفظ تلقائيًا في المتصفح.
- متابعة آخر درس ونسبة الإنجاز من صفحة «تعلّمي».
- اختبار من 5 أسئلة لكل دورة، مع شرح الإجابات وإمكانية إعادة المحاولة. الاجتياز من 80%، وتبقى أفضل نتيجة محفوظة.
- تصميم عربي متجاوب، وأرقام بصيغة 0–9، وصور تُحمّل عند الاقتراب من موضعها مع حجز مساحتها مسبقًا.

المشروع تجريبي لمعرض أعمال. يعمل بالكامل في المتصفح دون حسابات أو خادم خلفي. التقدم والملاحظات والنتائج محفوظة على الجهاز عبر `localStorage`، ويمكن مسحها من صفحة «تعلّمي». الصور والخطوط والأيقونات مرفقة محليًا.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل الخادم المحلي باستخدام Node.js 22 أو أحدث:

```bash
npm start
```

ثم افتح <http://127.0.0.1:4173>. تشغيل النسخة الجاهزة لا يحتاج إلى تثبيت الحزم.

## النشر على GitHub Pages

1. ارفع محتويات مجلد `madar-learning` إلى جذر المستودع، بما فيها ملف `.nojekyll`.
2. افتح **Settings → Pages**، واختر **Deploy from a branch** ضمن **Source**.
3. اختر فرع المشروع والمجلد **/(root)**، ثم **Save**.

المسارات نسبية وروابط الصفحات تبدأ بـ`#/`، لذلك يعمل الموقع تحت اسم المستودع. ملفات النشر جاهزة في الجذر، ولا تحتاج إلى إعداد بناء على GitHub.

## ملفات المشروع

| المسار           | المحتوى                                                    |
| ---------------- | ---------------------------------------------------------- |
| `index.html`     | الصفحة الجاهزة للنشر، مع محتوى الصفحات قبل تحميل التفاعلات |
| `style.css`      | التنسيق والتجاوب والطباعة                                  |
| `src/content.js` | الدورات والدروس والتدريبات والأسئلة                        |
| `src/core.js`    | حساب النتائج وتنقية البيانات المحفوظة والبحث               |
| `src/views.js`   | قوالب الصفحات                                              |
| `src/app.js`     | التنقل والتفاعل وحفظ التقدم والملاحظات                     |
| `assets/`        | الصور والخطوط والأيقونات وملف التفاعلات الجاهز             |
| `tools/`         | أدوات البناء والمعاينة والتصوير                            |
| `tests/`         | اختبارات المنطق وتجربة المتصفح                             |
| `screenshots/`   | 12 لقطة لصفحات الكمبيوتر والجوال                           |

## التعديل والبناء

```bash
npm ci
npm run build
npm start
```

عدّل المصدر في `src/` ثم أعد البناء لتحديث `index.html` و`assets/app.js`. تعديل `style.css` يظهر عند تحديث المتصفح دون إعادة بناء. تجنّب تعديل الملفات الناتجة عن البناء مباشرة، لأن البناء التالي سيستبدلها.

## الاختبارات واللقطات

بعد تثبيت الحزم:

```bash
npm test
npx playwright install chromium
npm run test:browser
npm run screenshots
```

تغطي الاختبارات حفظ التقدم والملاحظات، والتحقق من الإجابات، وإعادة الاختبار، والبحث، وقائمة الجوال، ومسح البيانات. تشمل مراجعة تجاوز عرض الشاشة وفحص إمكانية الوصول باستخدام axe. تعتمد اختبارات المتصفح والتصوير على فتح الملفات المحلية مباشرة.

يتوفر المتغير `BROWSER_PATH` لتحديد نسخة Chromium موجودة. ينتظر التصوير تحميل الصور والخطوط قبل حفظ اللقطات في `screenshots/`. تقارير الفحص في `test-results/`، وهو مستبعد من Git مع `node_modules/`.

لتنسيق المصدر، استخدم `npm run format`.
